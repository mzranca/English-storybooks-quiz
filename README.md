# 英文故事單字騎士 English Storybooks Quiz

從 YouTube 英文繪本朗讀影片學單字：看故事、填空選字、開口朗讀、聽整句發音，並追蹤每個單字有沒有真的學會。

**👉 立即使用：<https://mzranca.github.io/English-storybooks-quiz/>**

適合國小學童搭配家長或老師使用；手機、平板、電腦都能開。整個網站只有一個 `index.html`，不需要安裝、不需要註冊帳號。

## 功能介紹

### 1. 故事句子填空（主要測驗）

- 每一題是一個故事中的英文句子，其中一個單字被挖空，從 **四個選項** 中選出正確的字。
- 干擾選項會依照詞性挑選，避免放進空格也「文法上說得通」的字，讓答案只有一個。
- **中文翻譯**：一開始不顯示，選了答案之後（不論對錯）才會在句子下方出現整句中文翻譯。
- **影片對照**：每一題都有「到 YouTube 看這段」連結，直接跳到影片中這句話出現的時間；放在網站上時也可以在頁面中直接播放該段影片。
- **三種出題模式**：
  - 隨機 10 題
  - 全部題目（照故事順序）
  - 錯題複習（只出最近一次還沒答對的題目）

### 2. 朗讀練習（只記錄、不影響過關）

- 選對答案後進入朗讀練習，麥克風會自動聆聽，孩子直接唸出單字即可。
- 唸對會自動進入下一步；唸不出來或辨識不到，也可以按「下一步」繼續，**朗讀結果不影響是否過關**。
- 隨時可以按「🔊 聽正確唸法」聽單字發音；過關後會自動播放整句發音，也可以慢速重聽。
- 每一次測驗只需要允許一次麥克風權限。
- 每題的朗讀結果都會記錄為「唸對／沒辨識成功／沒錄到聲音」三種狀態，供參考。

### 3. 單字測驗（英翻中）

- 每個故事都有獨立的「單字測驗（英翻中）」按鈕。
- 單字順序隨機打亂，系統先唸出英文單字，從四個中文意思中選出正確答案。
- 每題作答後會顯示正確答案、詞性、故事原句與中文翻譯。
- 結束後顯示答對率與答錯的單字，可以只再練答錯的單字或整組重測。
- 意思太接近的干擾選項（例如 good／nice、bring／brought）會自動排除。

### 4. 學習紀錄

- **總覽**：選擇題一次答對率、朗讀唸對率、累計作答題數、練習次數。
- **最近 15 次練習圖表**：選擇題與朗讀的正確率。
- **各故事成績**：每個故事的練習次數、正確率、最近練習日期。
- **單字掌握度**：每個故事的單字列表，包含
  - 狀態：已學會／還沒學會／未練習（「已學會」＝最近一次作答時選擇題一次就選對）
  - 選擇題答對次數、英翻中答對次數、朗讀唸對次數
  - 最近 6 次作答紀錄（綠點答對、紅點答錯）
  - 曾經誤選的字
  - 可篩選「全部／還沒學會／未練習／已學會」
- **點單字看解釋**：點擊單字會跳出中文意思、詞性（名詞、動詞、形容詞…）、字形說明（例如 got 是 get 的過去式）、故事原句與翻譯，並可聽發音。
- **常錯單字** 與 **練習明細**。
- 可一鍵清除所有紀錄（會先確認）。

## 使用方式

1. 開啟 <https://mzranca.github.io/English-storybooks-quiz/>。
2. 建議先按故事卡片上的「先看影片」把故事看一遍。
3. 選擇測驗模式：
   - 「隨機 10 題」「全部 N 題」：句子填空＋朗讀練習
   - 「錯題複習」：只練還沒答對的題目
   - 「單字測驗（英翻中）」：只練單字意思
4. 第一次進入句子測驗時，瀏覽器會詢問是否允許使用麥克風，請按「允許」。
5. 練習完到「學習紀錄」查看成果，點「查看單字細節」看每個單字的掌握情形。

## 選字原則

- 題目答案都在 **英文最常用的 5,000 個字** 以內（依 [wordfreq](https://github.com/rspeer/wordfreq) 字頻排名），以高使用率字彙為主。
- 排除 a、the、is 這類過於基本的功能字。
- 同一個故事中每個單字只出一次題。
- 中文解釋依照 **該故事中的意思** 撰寫，例如 room 在〈Let's Have a Sleepover!〉是「空間；位置」，在〈Super Rabbit Boy〉是「房間」。
- 影片多為自動產生字幕，錯字（例如 Hedgehog 被辨識成 "Hot Jo"）已對照故事內容人工修正；押韻繪本（If I Built a… 系列）已整理成完整句子。

## 學習紀錄與資料儲存

- 所有作答紀錄都存在 **使用者自己的瀏覽器（localStorage）**，不會上傳到任何伺服器。
- 紀錄是「每台裝置、每個瀏覽器各自一份」：
  - 換電腦、換瀏覽器或使用無痕視窗，會看到空白紀錄。
  - 清除瀏覽器資料會一併刪除紀錄。
- 多位孩子共用同一台電腦時，建議各自使用不同的瀏覽器或瀏覽器使用者設定檔，紀錄才不會混在一起。
- 更新網站（重新上傳 `index.html`）**不會** 影響已存在的紀錄。

## 瀏覽器與裝置建議

| 項目 | 建議 |
|---|---|
| 瀏覽器 | **Chrome** 或 **Edge**（語音辨識效果最好） |
| 麥克風 | 第一次使用時請按「允許」；放在 GitHub Pages（https）上時，Chrome 會記住授權 |
| 直接開啟本機檔案 | 可以使用，但每次測驗都會詢問麥克風，而且 YouTube 不允許在頁面內播放影片（仍可用連結到 YouTube 觀看） |
| Safari／Firefox | 測驗與紀錄正常；語音辨識可能不支援，朗讀步驟可直接按「下一步」 |
| 發音 | 使用瀏覽器內建的英文語音（Text-to-Speech），不同裝置聲音可能不同 |

> 語音辨識對兒童聲音、口音與環境噪音較敏感，因此朗讀結果只做紀錄、不影響過關。
